Concurrency vs Parallelism

Two words everyone mixes up, one diagram that separates them.
01
Concurrency: many tasks making progress at once (interleaved).
02
Parallelism: many tasks running at literally the same time.
03
Concurrency is about structure; parallelism is about hardware.
04
You can have one without the other.
Concurrency is a code design. Parallelism is a hardware fact. Design for the first, measure the second.
