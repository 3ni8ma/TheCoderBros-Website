List vs Dict in Python

The single biggest performance decision in Python code.
1
List: ordered, indexed by position — great for sequences.
2
Dict: keyed lookup in O(1) — 'is this in here?' questions.
3
membership in list: O(n). membership in dict: O(1).
4
Rule: if you only store values to check existence, use a set.
# Slow: O(n) check inside O(n) loop -> O(n^2)
users = [{'id': 1, 'name': 'Ada'}, {'id': 2, 'name': 'Alan'}]
 
for order in orders:
    for u in users:
        if u['id'] == order['user_id']:
            # ...
 
# Fast: build a dict once, O(1) lookups -> O(n)
by_id = {u['id']: u for u in users}
for order in orders:
    u = by_id.get(order['user_id'])
Worth rememberingIf you ever write `if x in my_list` inside a loop, you probably want a set or dict.
